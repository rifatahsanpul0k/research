# Experiment ID system

Pattern: EXP-<SUITE>-<DATASET>-<METHOD>-<NNNN>, for example EXP-LN-A1-PCA-0001 and EXP-MB-E11-MULTIVI-0001. The ID denotes one immutable resolved configuration. A parameter or input change creates a new ID.

Engineering smoke tests use ENG-<METHOD>-<NNNN> and never occupy experiments.csv.
