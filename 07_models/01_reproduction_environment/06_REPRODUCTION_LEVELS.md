# Reproduction levels

R0 means paper and official code are verified. R1 means a pinned environment installs/imports. R2 means an official toy/example succeeds. R3 means a project dataset runs under the benchmark protocol. Phase 3B records R0 for every CORE candidate and permits small R1/R2 engineering checks. R3 is reserved for later authorization.

A failure to reach R1 is an engineering status. It is not poor scientific performance.
