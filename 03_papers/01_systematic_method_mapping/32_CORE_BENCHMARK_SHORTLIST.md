# Core benchmark shortlist

Phase 3A · 2026-09-12 · proposed design; no local performance results.

The core planning set must include diverse philosophies: separate/concatenation control, PCA or NMF, one factor/integration model, a generative method, a transport/alignment method where justified, and at least one graph/structural and one modern learned method. Core does not mean best; admission remains conditional on compatibility and Phase 3B reproducibility.

No model was trained, no benchmark was run, and no novelty claim is made.
