# Batch and biology trade-off

Phase 3A · 2026-09-12 · proposed design; no local performance results.

Integration should report technical mixing and biological conservation together. scIB-style metric families are useful references, but batch may be confounded with stage, donor, section or modality. A domain-invariant embedding can erase real biology. Report covariates, confounding checks, reference labels and any trade-off rather than optimizing one axis alone.
