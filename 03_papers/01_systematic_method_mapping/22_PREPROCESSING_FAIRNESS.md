# Preprocessing fairness

Phase 3A · 2026-09-12 · proposed design; no local performance results.

Use two tracks where possible: method-native preprocessing, which respects raw-count/LSI/graph contracts, and a standardized compatible input track for mechanisms that can share it. Never force raw-count likelihood models to consume an incompatible transformed scale. Record feature selection, normalization, PCA/LSI, graph construction and masks as pipeline inputs.
