# Deep representation comparison framework

Schema only; no scores or ranking. For every method record input axes and observation unit, encoder, decoder, deterministic/probabilistic output, objective, likelihood, contrastive pair/view rule, graph requirement, biological prior and release, modality and missing-view handling, uncertainty, inductive/transductive setting, parameter count only when reliable, official implementation, reproducibility, interpretability, downstream model, and evaluation reference. Architecture, objective, prior, task, and evaluation remain separate.
