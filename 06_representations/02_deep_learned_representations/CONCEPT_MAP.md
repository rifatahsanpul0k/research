# Phase 2C concept map

```text
biological observations X → feature/token/graph construction → encoder (AE/VAE/transformer/GNN) → objective (likelihood/reconstruction/contrastive/masked) → learned z (point/distribution/node embedding) → optional fusion/translation/decoding → downstream task + independent evaluation
```

Graph, hypergraph, heterogeneous, and multiplex structures are distinct. Shared/private latents are assumptions. Foundation pretraining is not biological understanding.
