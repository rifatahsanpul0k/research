# Phase 2B: classical representation families

This directory is the source-backed, unranked review of classical ways to represent tabular single-cell and spatial multi-omics data. Start with [representation principles](01_REPRESENTATION_PRINCIPLES.md), then use the numbered method/family notes, the [comparison framework](REPRESENTATION_COMPARISON_FRAMEWORK.md), and the [synthetic toy](TOY_REPRESENTATIONS.md). Sources and access limits are in [SOURCES.md](SOURCES.md); validation and stopping boundaries are in [VALIDATION.md](VALIDATION.md).

No project assay was transformed or fitted. No family is ranked. Graphs are one branch among vectors, factors, pairwise objects, neighborhoods, couplings, tensors, sets, prototypes, distributions and biological-prior summaries. Phase 2C is outside this directory and has not started.
